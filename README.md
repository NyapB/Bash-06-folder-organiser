# 🏷 Folder Organizer

> A program that organizes files of the same category in a folder in to separate folder

## 📌 Problem Statement

a bunch of disorganized files in a folder can make it difficult for easy querying and retrieval of files. Arranging them intto folders of same category eases the retrieval process

## 🎯 Project Goals

- allows users to sort the files according to categories
- Enables users to create separate folders for separate categories
- avoids overwriting files
- safe time and energy for sorting and retrieving

## 🛠 Tech Stack

- Git & GitHub  
- language/shell
- Bash

## 🖥 Features

- enter folder name
- Error handling
